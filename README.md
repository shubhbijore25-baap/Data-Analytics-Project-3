# SQL Data Analysis - DecodeLabs Project 3

## 📌 Project Overview
This project performs relational data extraction, aggregation, and filtering on an e-commerce order dataset using **MySQL Workbench**. The objective is to extract key business insights through structured SQL logic.

---

## 🛠️ Key SQL Capabilities Demonstrated
* **Basic Querying:** Retrieving columns using `SELECT` and `FROM`.
* **Aggregations:** Calculating global metrics using `COUNT()`, `SUM()`, and `AVG()`.
* **Filtering Data:** Applying row-level conditions with `WHERE`.
* **Categorical Grouping:** Organizing metrics by segment using `GROUP BY`.
* **Group Filtering:** Filtering aggregated result sets using `HAVING`.
* **Sorting & Limits:** Ranking outputs using `ORDER BY` and `LIMIT`.

---
